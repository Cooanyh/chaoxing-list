# 任务引擎与统一设置设计

## 目标

在不执行、提交或代办任何学习任务的前提下，将课程任务、作业、视频/任务点、AI 实践、分组讨论、测验和考试聚合为可筛选的学习清单，并集中管理显示和忽略规则。

## 数据策略

- 课程活动继续从 `mobilelearn` 的活动清单读取，用于任务明细和跳转。
- 视频/任务点由课程进度板块统一呈现，不在任务清单重复生成课程级摘要。
- 活动类别先按接口类型映射，再按标题兜底识别 AI 实践、考试、测验与分组讨论。
- 每个任务保留课程 ID、班级 ID 与课程名，以便统一过滤和跳转。
- AI 实践在展示层并入作业列表，并从课程任务列表排除，避免重复。

## 设置与忽略

- 默认显示核心任务：作业、视频/任务点、AI 实践、分组讨论、分组任务、测验、随堂练习、考试。
- 签到、问卷、抢答、通知、投票、直播等属于“其他任务”，默认不展示；首次打开仪表盘会提示用户可在设置中开启。
- 忽略总开关默认关闭。关闭时不显示忽略、多选和已忽略入口，且不清除已有记录。
- 课程多选忽略用 `courseId + clazzId` 作为持久化键；命中课程后，其所有板块与类别的任务都会被过滤。
- 课程进度加载在发起 API 请求前排除已忽略课程；加载期间新被忽略的课程也会跳过后续尚未发送的请求。
- 动态忽略规则可持续过滤当前与未来出现的已完成或已过期项；取消规则只停止动态过滤，不会删除或恢复用户逐条手动忽略的记录。
- 首页完整加载待办、作业、考试、课程任务、课程进度及高优先级信息；课程任务读取结果同时供待办使用，避免为首页重复遍历课程。设置课程列表、课程进度悬浮详情等非首屏资源按需请求。
- 短时缓存默认关闭。用户开启后，课程任务和课程进度可在 5 分钟有效期内先展示缓存，并标注“缓存内容，正在更新”；后台读取成功后立即替换，过期项会在启动、读写及定时清理中删除。

## 验证边界

- 静态验证：脚本语法、差异空白检查与本地数据逻辑检查。
- 已登录浏览器验证：确认新版课程任务页、任务引擎请求和设置 UI 可用；不点击任何会改变学习状态的课程任务按钮。
- 真实课程数据随账号和课程状态变化，接口返回的具体数量不写入脚本的固定判断。
